# ADR-0001: 使用匿名所有者令牌与分能力链接模型

## Status
Accepted

## Context

产品目标是无需登录即可创建和访问 Markdown 分享链接，同时又要支持后续编辑、设置修改和删除。

如果不引入账号体系，仍然需要一种方式识别“创建者”以及“可编辑访问者”的权限能力。单一链接同时承担访问、编辑和管理职责会放大误操作和泄露风险，也不符合轻量分享工具的安全边界。

## Decision

采用匿名令牌模型：
- 普通访问使用公开短链接
- 编辑能力通过编辑链接授予
- 管理能力通过管理链接授予

访问、编辑、管理三种能力分离。

敏感令牌仅向创建者展示，优先通过 URL Fragment 传递，服务端只存储令牌哈希值。

## Consequences

### Positive
- 无需登录即可保留后续管理能力
- 查看与编辑权限边界清晰
- 泄露访问链接不会自动泄露管理能力
- 符合“轻量、临时、匿名”的产品定位

### Negative
- 用户需要理解“访问链接”和“管理链接”的区别
- 管理链接丢失后无法像账号体系那样找回
- 前端需要处理本地缓存管理能力

### Neutral
- 未来若增加账号体系，仍可兼容匿名令牌方案

## Alternatives Considered

### 单链接承载所有能力

被拒绝，因为：
- 权限过大
- 链接泄露风险高
- 不利于分享给不同对象

### 账号登录后管理

被拒绝，因为：
- 与“无需注册即可创建/访问”的核心定位冲突
- 显著提高首次使用成本
